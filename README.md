**ATV Hub** — современный медиакомбайн и лаунчер для **Android TV / Google TV**, объединяющий каталог медиа с двумя движками воспроизведения (онлайн-потоки и торренты), IPTV-плеер с телегидом, каталог приложений с поддержкой ТВ-входов и глубокую интеграцию со SmartTube.

Разрабатывается как независимое нативное приложение на **Kotlin** под Android TV.

Полное техническое описание и архитектура проекта зафиксированы в документе **[SPECIFICATION.md](SPECIFICATION.md)**.

## 🌟 Ключевые возможности

### 🎬 Двойной движок воспроизведения (Онлайн-потоки и Торренты)
* **«Смотреть» (Онлайн)**: поиск и запуск бесплатных потоков из Rutube, VK Видео и открытых балансеров (Kodik, Alloha, Collaps). Отбор только русскоязычных дорожек (`RU`) в качестве не ниже `720p`. Позволяет смотреть кино даже при строгих блокировках P2P-трафика провайдером.
* **«Торренты» (P2P)**: интеграция с TorrServe, раздачи с трекеров с выбором сидов, размера, кодеков (HDR10, Dolby Vision) и звуковых дорожек.
* **Трейлеры и Мой список**: быстрый запуск официальных трейлеров и добавление контента в избранное.

### 📺 Интеграция со SmartTube
* **Лента «Подписки» на главном экране**: системная интеграция через Android Leanback `TvContract` (`content://android.media.tv/preview_program`).
* Располагается строго после Топ-10 фильмов и Топ-10 сериалов.
* Прямой запуск роликов в плеере SmartTube и бесшовный возврат на домашний экран.

### 📱 Приложения и ТВ-входы (Apps & TV Inputs)
* **Стандартные карточки Android TV 16:9** со скругленными углами и подписями под карточками.
* **Сетка 4 колонки** с плавной вертикальной прокруткой без горизонтального скролла строк.
* **Секция ТВ-входов** (HDMI 1, HDMI 2, HDMI 3, AV) с прямым переключением физических источников через `TvContract`.
* Постоянное левое меню навигации.

### 📡 Онлайн ТВ (IPTV)
* Поддержка пользовательских M3U/M3U8 плейлистов и телегида EPG (XMLTV).
* Раздел управления и обновления плейлистов вынесен в **«Настройки» → «Онлайн ТВ»**.

### 🎨 OLED-Safe дизайн и эргономика
* Темная цветовая палитра (`#000000` / `#080B10`) с фиолетовым акцентом (`#7C4DFF`).
* Полная оптимизация под ТВ-пульт (D-Pad) и ПК-клавиатуру без залипаний в Touch Mode.

## 🛠 Сборка проекта

Проект собирается стандартным Gradle wrapper:

```bash
# Сборка Release APK
./gradlew assembleRelease

# Сборка Debug APK
./gradlew assembleDebug
```

Собранный APK сохраняется в папку: `app/build/outputs/apk/release/`

Для быстрого запуска и тестирования в эмуляторе:
* `start-emulator.bat` — запуск AVD `ATV_11`
* `install-to-emulator.bat` — автоматическая установка и запуск приложения на эмуляторе
