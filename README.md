# ATV Hub 📺

**ATV Hub** — современный, быстрый и стильный лаунчер-медиацентр для Android TV (ATV 9+) с фокусом на удобство управления пультом ДУ (10-foot UI), глубокой интеграцией **SmartTube** и мощным онлайн-каталогом медиа.

Проект создан на базе потрясающего приложения **Flux TV** и расширен до полноценного домашнего экрана (лаунчера) Android TV.

---

## 🌟 Ключевые возможности

### 📺 Интеграция со SmartTube
* **Лента «Подписки» на главном экране**: автоматическая синхронизация с каналом подписок SmartTube через системный Leanback TvProvider (`content://android.media.tv/preview_program`).
* **Прямой запуск роликов**: выбор любой карточки мгновенно запускает видео в полноэкранном плеере SmartTube (`PlaybackActivity`).
* **Бесшовный возврат**: нажатие кнопки «Назад» (BACK) из плеера возвращает пользователя прямо на главный экран ATV Hub.
* **Фолбэк-карточка**: быстрый запуск приложения SmartTube, если лента временно пуста.

### 🎬 Каталог фильмов и сериалов
* **Главный экран**: подборки цифровых новинок, популярных фильмов, сериалов и трендов.
* **Торренты и онлайн-просмотр**: стриминг через TorrServer и открытые балансеры с выбором дорожек и озвучек.
* **Детальная информация**: постеры в высоком разрешении, описания, рейтинги, актерский состав и трейлеры.

### 📱 Управление приложениями и ТВ
* Быстрый доступ и запуск установленных на телевизоре Android-приложений прямо из бокового меню и главного экрана.
* Поддержка IPTV плейлистов (M3U/M3U8) и программы передач (EPG).

### 🎨 Дизайн и эргономика
* Полноценный интерфейс на **Jetpack Compose TV**.
* Контрастная обводка активного элемента для комфортной D-Pad навигации с любого расстояния.
* Элегантная темная тема с фирменным фиолетовым акцентом.

## 🚀 Установка

1. Перейдите в раздел **[Releases](https://github.com/ntvampire/ATV-Hub/releases)**.
2. Скачайте свежий релизный APK-файл (например, `ATV-Hub-v1.1.0.apk`).
3. Установите на ваше Android TV устройство любым удобным способом:
   * через **ADB**:
     ```bash
     adb install -r -d ATV-Hub-v1.1.0.apk
     ```
   * с помощью флешки через любой файловый менеджер на ТВ;
   * через приложение **Downloader** на телевизоре по прямой ссылке.

## 🛠 Сборка из исходников

В репозитории подготовлены автоматические скрипты сборки и деплоя:

* **Сборка релизного APK**:
  ```powershell
  .\scripts\build-release.ps1
  ```
  *Компилирует `bridge/SmartTubeBridge.java`, патчит smali-код и собирает подписанный `dist/atv_hub.apk`.*

* **Установка на эмулятор / устройство**:
  ```cmd
  install-to-emulator.bat
  ```

* **Запуск тестового эмулятора**:
  ```cmd
  start-emulator.bat
  ```
