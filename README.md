# ATV Hub 📺

**ATV Hub** — универсальный лаунчер-медиаплеер для Android TV (ATV 9+) в строгом матовом кинематографичном дизайне под пульт (10-foot UI).

---

## Ключевые возможности

* **Главный экран и управление лентами:**
  * Быстрый запуск приложений (Кинопоиск, Wink, SmartTube и др.) с возможностью сортировки.
  * Лента продолжения просмотра (история и таймлайн).
  * Цифровые новинки кино и сериалов в стиле **NUM** (только реальные 720p+/торрент-релизы **без экранок**).
  * Избранное и отслеживание новых серий.
  * Перемещение и включение/отключение любых лент.
* **Торренты и онлайн:**
  * Поиск раздач через **JacRed** с фильтрацией по качеству/сидам и **строго из зоны RU** (Rutor, Rutracker, NNM-Club, MegaPeer и др. с русскоязычными дорожками).
  * Потоковое воспроизведение через встроенный или внешний **TorrServer Matrix**.
  * Поддержка онлайн-потоков 720p+ (открытые балансеры, VK Видео, Rutube) с выбором озвучки.
* **IPTV Плеер:**
  * Загрузка своего M3U/M3U8 плейлиста и XMLTV телепрограммы (EPG).
  * Закрепление избранных каналов в отдельную строку на домашнем экране.
  * Полноэкранный плеер со шторкой категорий и списком передач.
* **SmartTube:**
  * Отображение лент рекомендаций и подписок напрямую из SmartTube через Android TV Recommendations API.
* **Автообновление (OTA):**
  * Встроенная проверка новых релизов через GitHub Releases API прямо из настроек с установкой в один клик.
* **Дизайн:**
  * «OLED Black» палитра без градиентов и переливов.
  * Четкий контрастный фокус D-Pad (белая контурная рамка) для комфортного управления с 3 метров.

## Сборка и релизы

Сборка осуществляется автоматически через **GitHub Actions**:
* При пуше тега `v*.*.*` собирается релизный APK: `ATV-Hub-vX.Y.Z.apk`.
* Готовый файл автоматически публикуется в раздел [Releases](https://github.com/ntvampire/ATV-Hub/releases).
